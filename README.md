## เกี่ยวกับผม

สวัสดีครับ รับงานได้ทั้งสายเทคโนโลยีและงานทั่วไป ด้านเว็บและแอป เคยสร้างเว็บไซต์ร้านขายดอกไม้ให้ธุรกิจจริง และพัฒนาแอป Rewear ซึ่งเป็นตัวกลางที่พาผู้ซื้อและผู้ขายมาเจอกัน ส่วนงานทั่วไป ผมพร้อมรับงานที่ต้องใช้แรงและงานรับจ้างหลากหลายประเภท ทำงานตามที่ตกลง สื่อสารชัดเจน และรับผิดชอบงานจนเสร็จ

## บริการที่รับทำ

### งานด้านเว็บและแอป

| บริการ | เหมาะกับ | เทคโนโลยี |
|---|---|---|
| เว็บไซต์ร้านค้า / ธุรกิจขนาดเล็ก | ร้านดอกไม้ ร้านอาหาร ร้านค้าออนไลน์ที่ต้องการหน้าเว็บของตัวเอง | HTML, CSS, JavaScript |
| Landing Page | โปรโมตสินค้า โปรโมชัน หรือเก็บรายชื่อลูกค้า | HTML, CSS, JavaScript |
| แอปมือถือ | ไอเดียแอปที่ต้องการต้นแบบหรือใช้งานจริง | Dart, Flutter |
| แก้ไข / ปรับปรุงเว็บเดิม | เว็บที่มีอยู่แล้วแต่ต้องการแก้บั๊กหรือปรับหน้าตา | HTML, CSS, JavaScript, TypeScript |

### งานทั่วไปและงานรับจ้าง

| บริการ | ตัวอย่างงาน |
|---|---|
| งานใช้แรง | ขนย้ายของ จัดเรียงสินค้า ยกของ ช่วยงานอีเวนต์หรืองานร้าน |
| งานรับจ้างทั่วไป | ช่วยงานจิปาถะ งานธุระ รับ-ส่งของ ช่วยเหลืองานรายวัน |
| งานทั่วไปด้านเอกสารและข้อมูล | พิมพ์เอกสาร กรอกข้อมูล จัดระเบียบไฟล์ ทำตารางข้อมูล |

> ขอบเขตและราคาขึ้นอยู่กับรายละเอียดงาน ทักมาคุยก่อนได้ครับ งานไหนที่ไม่อยู่ในรายการ สอบถามได้เสมอ

- [ดูโค้ดบน GitHub](https://github.com/PakornBtfaf/LandokmaiWeb)

แอปพลิเคชันที่ช่วยให้ผู้ซื้อและผู้ขายมาเจอกันได้ง่ายขึ้น

- เทคโนโลยี: Dart, Flutter
- [ดูโค้ดบน GitHub](https://github.com/PakornBtfaf/RewearApplication)

## ขั้นตอนการทำงาน

1. **คุยความต้องการ** : แจ้งรายละเอียดงาน สถานที่ (ถ้าเป็นงานทั่วไป) เป้าหมาย และงบประมาณ
